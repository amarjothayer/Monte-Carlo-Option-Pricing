# Monte Carlo Option Pricing

## Overview
This project explores option pricing using Monte Carlo simulation. It focuses on implementing and analysing the method through comparison with the analytical Black-Scholes model for European options and demonstrates its use for pricing exotic options. The aim is to highlight key aspects of Monte Carlo simulation, such as its convergence behaviour and the effect of variance reduction techniques.

## Key Features
- Implementation of analytical Black-Scholes and Monte Carlo option pricing models.
- Comparison of Monte Carlo estimates against the exact Black-Scholes benchmark for European call options.
- Analysis of Monte Carlo convergence and standard error behaviour.
- Demonstration of variance reduction using antithetic variates.
- Application of Monte Carlo to pricing exotic options.
